# ONG Esperança

## Sobre o projeto

A ONG Esperança é uma aplicação web desenvolvida para apresentar uma organização do terceiro setor, seus projetos sociais e informações de contato.

O projeto foi desenvolvido como parte das atividades práticas, com foco em HTML, CSS, JavaScript, responsividade, acessibilidade e controle de versões.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Funcionalidades

- Página inicial com informações sobre a ONG;
- Página de projetos sociais;
- Formulário de cadastro;
- Menu de navegação responsivo;
- Menu dropdown;
- Menu hambúrguer para dispositivos menores;
- Componentes de feedback;
- Validação de formulário;
- Navegação dinâmica utilizando JavaScript e DOM.

## Responsividade

A interface foi desenvolvida utilizando:

- CSS Grid;
- Flexbox;
- Media Queries;
- Breakpoints para diferentes tamanhos de tela.

O objetivo é proporcionar uma boa experiência tanto em computadores quanto em dispositivos móveis.

## Acessibilidade

Foram utilizadas práticas de acessibilidade como:

- HTML semântico;
- Textos alternativos nas imagens;
- Contraste adequado entre texto e fundo;
- Navegação por teclado;
- Estrutura organizada de títulos e seções.
